    Direct browser mode

    This single file opens two temporary guest connections to Pokémon Showdown: one for you and one for the dojo bot. The official server deals the random teams and resolves every turn; the bot chooses locally in this page.

    • No account, room list, ladder, cookies, or saved history.
    • Nothing is stored after you close the tab.
    • If a school, work, or browser network blocks WebSockets or guest sign-in, the match cannot start.

    The file talks only to sim3.psim.us for battle messages and play.pokemonshowdown.com for temporary guest assertions, move data, Pokédex data, and battle sprites.
